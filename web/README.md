# 衣橱 Capsule 网页体验版

这是智能胶囊衣橱的浏览器版本地体验。数据保存在当前浏览器的 LocalStorage 中；上传的图片也只保存在当前浏览器。

## 本地启动

```bash
cd web/dist
python3 -m http.server 4173
```

然后打开 <http://localhost:4173>。

## 当前功能

- 浏览、筛选和多选衣物
- 从本地添加衣物照片和标签
- 将已选衣物加入搭配工作台
- 生成基于标签的本地搭配建议
- 在浏览器中保留衣物与搭配数据

此网页目前不调用 DeepSeek，也不会上传数据到 CloudBase。后续接入云端时，前端将改为调用与小程序一致的云函数。
